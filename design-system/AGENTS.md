# Instructions for AI agents

This folder is Bloomgard Jaali, the design system for all Bloomgard interfaces.

Before writing or changing any UI, read `SKILL.md` in this folder and follow its rules. For questions it does not answer, read `DESIGN.md`. Take colours, type, spacing and radii only from `tokens/tokens.css` (or `tokens/tailwind.css` in Tailwind projects), and reuse the classes in `css/jaali.css` before writing new component styles. Use the files in `assets/` for logos, product glyphs and motifs; never redraw them.
